## When every cell matches

```
node tools/record-spot-check.mjs interlake-2026-09 --checked-by "Your Name" --matched
```

It copies the pinned cells verbatim into `human_spot_checks`, in the drawn order. It will not
let you record cells other than the ones drawn — that is the whole point of the gate, and
hand-editing the JSON is how you spend an hour reading a chart and then get refused on a typo.

`--matched` is required and has no default: a default would be a signature nobody typed.

## If any cell does not match

```
node tools/record-spot-check.mjs interlake-2026-09 --checked-by "Your Name" \
  --failed "59E/F5M/120in reads 7530 on p.88, extract says 7330"
```

Do not record a partial pass. One wrong cell fails the WHOLE release: it means the extract has
a defect of unknown extent, so the remedy is a corrected extract and a fresh draw, not a note.
`interlake-2026-09` stays DRAFT until then.

That is not a setback. It is the control doing the only job it has, and it is the job the
reference data's 72% overstatement got through because nobody was doing.
